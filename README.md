# Рыжик и тайная картинка

Детская игра для малышей 3–6 лет: веди лисёнка Рыжика по полю и открывай спрятанную картинку. Управление пальцем или стрелками, пчёлки медленные, при столкновении — мягкий откат и можно пробовать снова.

Это основа: три уровня, захват области, экраны старта, выбора, игры, победы и коллекции. Звуков пока нет.

## Как запустить

Нужен Node.js 20 или новее.

```bash
npm install
npm test
npm run dev
```

Игра откроется на http://127.0.0.1:5173/

Сборка для публикации:

```bash
npm run build
npm run preview
```

Прогресс хранится только на устройстве (localStorage), никуда не отправляется. Сайт рассчитан на офлайн-работу, в том числе из Беларуси и России: без внешних CDN, аналитики и онлайн-шрифтов.

Публикация на GitHub Pages настроена через Actions (ветка `main`, папка `dist`). В настройках репозитория источник Pages нужно поставить в «GitHub Actions».

## Как наложить патч на пустой репозиторий

Если в репозитории ещё нет коммитов:

```bash
git clone https://github.com/PavelLahutsin/ryzhik-tajnaya-kartinka.git
cd ryzhik-tajnaya-kartinka
git am --binary /путь/к/ryzhik-tajnaya-kartinka-patch/*.patch
```

Первый патч — короткий начальный коммит, второй — ветка `foundation` с самой игрой. После `git am` переключитесь на `foundation`, если нужно открыть pull request, и не забудьте проверить `npm install && npm test && npm run build`.
